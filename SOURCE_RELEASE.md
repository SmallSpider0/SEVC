# Source distribution scope

This is a static source snapshot of SEVC's maintained implementation and main
experiment code. It is not the ongoing development repository.

Included: selected canonical source, parameter configurations, tests that
generate synthetic inputs at runtime, input documentation, and packaging files.

Excluded: datasets and saved samples, model states, recorded calibration values,
experiment results, plots, logs, private random streams, deployment receipts,
private machine/account information, original version-control history, and
manuscript/workflow materials.

The public scientific protocol preserves three datasets and 15 packages. A new
execution supplies its own data, calibration, streams, environment, and run ID.
It cannot be presented as the original study's evidence. Software tests are not
scientific measurements. Earlier experiment code is retained as scientific
routines without private deployment orchestration; see docs/experiments.md.

No remote repository or release is created by this source preparation. License
selection remains an owner action before public distribution. A fresh local Git
repository may be initialized without importing previous history or identity.
